T3XTURE BRAND KIT  v3.0
=======================

THE SYMBOL — "THE TILE"
A square with two opposite quarter-circles cut away: half hard edge, half curve.
It is a single Truchet tile. Alone it is the mark. Repeated with random 0°/90° rotations
it becomes the T3xture pattern, so every banner and cover points back to the symbol.

WHICH FILE DO I USE?
  Website header ....... Logo/Light/T3xture_Logo_Horizontal_Light.svg   (Logo/Dark/ on dark sites)
  Profile pictures ..... Social/T3xture_Avatar_Dark_1080px.png
                         GitHub, LinkedIn, X, Instagram, Discord. Square, safe for circular crops.
  Profile banners ...... Pattern/T3xture_Banner_X_*_1500x500.png, Pattern/T3xture_Banner_LinkedIn_*_1584x396.png
  Favicon .............. Favicon/   (paste favicon-head-snippet.html into <head>)
  CV / documents ....... Logo/Monochrome/T3xture_Logo_Horizontal_Mono_Black.svg
  Stickers / projects .. Symbol/   (standalone symbol, app tiles)

FOLDERS
  Logo/      horizontal + stacked lockups (symbol + wordmark)
  Symbol/    standalone symbol + app tiles
  Wordmark/  lettering only
    each with Light/ (for light backgrounds), Dark/ (for dark backgrounds),
    Monochrome/ (pure #000 / #FFF)
  Social/    square avatars, 1080 + 400 px: Dark (default), Light, Signal
  Pattern/   brand pattern (2400 px) + X and LinkedIn banners, Dark / Light / Signal
  Favicon/   favicon.ico (16/32/48), favicon.svg, PNGs, apple-touch, android-chrome, manifest
  Source/    master artboard SVG (named groups), construction sheet, tokens JSON, palette CSS

Logo, Symbol and Wordmark PNGs are transparent. Avatars, tiles, patterns and touch icons are opaque by design.
All SVG shapes are filled paths (no fonts, no strokes on the logos), cropped tight, print-ready.

RULES
  Clear space: 1/4 of the symbol height on every side.
  The standalone symbol always has its cut corners at top-left and bottom-right. Only patterns rotate it.
  One color per symbol. Never outline, gradient, or add effects.

COLOR
  Ink      #0E0E0E   primary
  Paper    #F2F0EB   primary
  Signal   #FF4F1F   optional accent (pattern backgrounds, highlights). Never inside the symbol.
  Graphite #2A2927   secondary dark surface
  Stone    #8A867E   secondary text

TYPE
  Wordmark      Geist Medium, tracking -1.5%, outlined. Never retype it.
  Headings/UI   Geist 500-600      Labels/metadata   Geist Mono   (free, SIL OFL)
